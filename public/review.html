Owner review desk

Read the source. Write the question. Verify the answer. Publish deliberately.

No AI. No automatic approval.

This public page is a local authoring tool, not a secure admin backend. It cannot publish or modify the live website. Only someone with repository write access can publish the downloaded bank. Reviewer names are declarations, not authenticated identities. Never enter access tokens here.

Headlines are collected automatically. To add a usable MCQ, you must read the original source, write both language versions, check the answer and distractors, and approve it. News does not become a question merely because it was fetched.

To retain unpublished drafts from another device, import your repository's content/live-questions.json first. Local drafts on this browser are merged with the published bank. Export a backup before importing another bank.
